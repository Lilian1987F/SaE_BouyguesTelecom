# Présentation du projet
Dans le cadre de notre SaÉ, nous créons un site web informatif pour Bouygues Telecom. L'objectif est de présenter l'entreprise et son positionnement sur le marché des télécommunications. Le site s'appuiera sur des informations économiques ainsi que d'autres types d'informations. Ce projet nous permet de mettre en pratique nos compétences web tout en approfondissant notre compréhension du secteur. Nous avons l'intention de réaliser un site digne de la marque, en mobilisant toutes nos connaissances afin de nous améliorer pour les projets futurs.
